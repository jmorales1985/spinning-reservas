# RPM Spinning

App web (PWA) para reservar bicis en una sala de spinning de 26 bicis numeradas, acomodadas en arcos alrededor del instructor, como asientos de cine.

- Frontend: un solo `index.html` (sin build). Despliegue en Vercel desde GitHub.
- Backend: Supabase (proyecto propio `spinning-reservas`, cuentas independientes de Pinto & Pesas). Esquema en `supabase/schema.sql`.
- Login: correo y contraseña, recordar correo, cierre de sesión a los 5 minutos sin uso.
